## C++与C的关系
C++包含了C的所有成分。
C++在C的基础上增加了一些新的语言机制：
- 更好地支持过程式编程，提高与类型相关的安全性。（C++对C的基本扩充）
- 支持面向对象编程。
- 支持泛型编程。
- 支持函数式编程。
## 基本扩充内容
- **局部变量的定义位置**：
	- 允许局部变量的定义可以加插在语句中
	- 变量的使用点和定义点相距不至于太远，便于理解与维护
- **常量定义**：
	- `#define PI 3.1416` （编译前的预处理时会将PI替换为3.1416）
	- C++补充了const double PI = 3.1416，便于编译时进行类型检查
- **表示条件的表达式**：
	- 值非0表示满足，0表示不满足
	- bool类型：true表示满足，false表示不满足（C++扩充的，便于理解）
- **内联（inline）函数**：编译时把函数体嵌入到函数的调用点，提高对小函数的调用效率
- 可以给函数的参数指定默认值
- **名空间（namespace）**：不同模块可以有同名的全局实体，应对名冲突问题
- **标准库**：保留了c的标准库，将头文件名从`*.h`改为`c*`，如`stdio.h`改为`cstdio`
- **函数名重载**：**同一个作用域内**功能相同、参数不同的函数取相同名字
- **动态变量的内存分配**：增加了新的操作符`new`与`delete`，保证类型安全。
- **引用类型**：具有指针的一些作用，但比指针更安全。
- **基于范围的for语句**：自动遍历数组元素，防止数组下标越界
- **类型自动判断auto**：根据初始化的值自动判断变量的类型，方便某些类型变量的定义
- **结构化异常处理**：把程序的正常处理与异常处理的代码分离开，使得程序容易理解与维护。
- **匿名函数（λ表达式）**：把函数定义和使用合而为一，方便对一些临时函数的使用。
- **输入/输出**：保证类型安全的输入输出（cin、cout等）

下面的函数会在C++练习中频繁使用，在这里提前介绍：
### 输入输出
对于下面的变量
```cpp
int x; double y;
```
输入：
```cpp
scanf("%d%lf",&x,&y); //C语言做法，类型不安全！
cin >> x >> y; //C++扩充，自动判断输入数据的类型。
    //cin为特殊类型的变量（对象），“>>”为重载的操作符
```
输出：
```cpp
printf("%d,%f\n",x,y); //C语言做法，类型不安全！
cout << x << ',' << y; //C++扩充，自动判断输出数据的类型。
    //cout为特殊类型的变量（对象），“<<”为重载的操作符
```

### 解决对小函数调用的低效问题：内联函数
函数调用需要额外开销（保留返回地址、为局部变量和形参分配空间等），对只包含一两句的小函数，过于低效。
解决办法：
- 带参数的宏 如`#define max(a,b) (((a)>(b)?(a):(b))`
	- 在编译前会将`max(a,b)`替换为`(((a)>(b)?(a):(b))`，效率比定义一个`max`函数高
	- 宏定义的不足之处：
		- 要加上很多的括号以保证不出问题
		- 有时会出现重复计算
		- 替换时没有参数类型检查和转换
- **内联函数**：定义函数时，在函数返回类型之前加上一个`inline` 如：
```cpp
Inline int max(int a, int b) {   return a>b?a:b;   }
```
- 内联函数的作用是*建议编译程序把该函数的函数体展开到调用点*，函数调用时直接执行函数
书写时：
```cpp
cout << max(a,b)
```
编译时，编译器会自动将上述代码改为
```cpp
cout << (a>b?a:b)
```
随后再进行编译。
- 内联函数形式上属于函数，遵守函数调用的规定
- 不是所有函数都能作为内联函数，比如递归函数无法内联
- 内联函数名具有*文件作用域*

### 带缺省的形式参数
在C++中允许在声明函数时，为函数的某些参数指定默认值。例如，可以把函数print声明成：
```cpp
void f(int value, int base=10);
```
在对这些函数调用的地方，如果没有提供相应的实参，则相应的形参采用指定的默认值。例如：
```cpp
f(32,2); //32传给value；2传给base
f(28); //28传给value；10传给base
```

在指定函数参数的默认值时，应注意下面几点：
- 有默认值的形参应**全处于形参表的右部**。例如：
```cpp
void f(int a, int b=1, int c=0); //OK
void f(int a, int b=1, int c); //Error，c没指定默认值
``` 
- 对参数指定默认值只在函数声明（包括定义性声明）处有意义，因为对函数调用的编译要用到它。
	- 在不同的源文件中，对同一个函数的声明可以对它的参数指定不同的默认值。
	- 在同一个源文件中，对同一个函数的声明只能对它的每一个参数指定一次默认值。例如：
```cpp
void f(int a, int b, int c=2); //Ok，函数f的声明
......
void f(int a, int b=1, int c=0);  //Error，对参数c指定了两次默认值
......
```
### static声明
- static 用在全局变量前，可使该变量只能在该文件内部使用，不能跨文件使用
- 用在局部变量前，可使该变量的寿命与全局变量相同
- 此外，static还可用于声明静态成员，具体参考文章[[10.常成员函数及静态成员]]

### 名空间
对于一个由多个模块（源文件）构成的程序，有时会面临一个问题：
在一个模块中要用到在另外两个模块中定义的不同全局程序实体（如：全局变量和函数），而这两个全局程序实体的名字相同。
例如，在下面的模块1和和模块2中都定义了x和f，模块3中如何分别使用它们？
```cpp
//模块1
int x=1;
void f()
{ ......
}
```

```cpp
//模块2
int x=0;
void f()
{ ......
}
......
```

```cpp
//模块3
extern int x; //?
extern void f(); //?
......
... x,f ... //?
......
```

C++提供了**名空间**（namespace）机制来解决上述的名冲突问题： 
可以把全局标识符定义在一个名空间中，其作用域为该名空间。
当在一个名空间外部需要使用该名空间中定义的全局标识符时，需要用该名空间的名字来修饰或受限。

```cpp
//fileq.h
namespace A
{ int x=1;
 void f() { ...... }
}
```

```cpp
//file2.h
namespace B
{ int x=0;
 void f() { ...... }
}
```

```cpp
//main.cpp
#include "file1.h"
#include "file2.h"

//可按下列1、2、3三种方式使用模块1和模块2中的实体
/* 1 */
... A::x ...  //A中的x 
A::f();  //A中的f
... B::x ...  //B中的x
B::f();  //B中的f

/* 2 */
using namespace A;
... x ...  //A中的x 
f();  //A中的f
... B::x ...  //B中的x
B::f();  //B中的f

/* 3 */
using A::f;
... A::x ... //A中的x 
f(); //A中的f
... B::x ...  //B中的x
B::f();  //B中的f
```

由于C++标准库中的全局实体（如cin、cout）是定义在名空间std中的，因此，使用标准库中的全局实体时要用**std受限**。
另外，具有文件作用域的标识符可以用**无名的名空间**来定义。
例如，对于下面用static说明的具有文件作用域的全局变量：
```c
static int x,y; //C语言的做法
```
可用下面的无名的名空间来代替：
```cpp
namespace {  
	int x,y; //x和y只能在本源文件中使用！
}
```
这样，static就可以只用于一个目的了：使得局部变量采用静态存储分配。


### 动态变量
在C语言中，动态变量是用库函数来创建和撤销的。例如：
下面创建一个int型动态变量，p1指向之：
```c
int *p1; //p1是个指针变量
p1 = (int *)malloc(sizeof(int)); //分配sizeof(int)大小的空间
```
下面创建一个由n个int型元素构成的动态数组，p2指向其第一个元素：
```c
int *p2; //p2是个指针变量
p2 = (int *)calloc(n,sizeof(int)); //元素初始化为0
```
或
```c
p2 = (int *)malloc(sizeof(int)*n);
```
下面撤销p1指向的int型动态变量和p2指向的动态数组：
```c
free(p1);
free(p2);
```

在C++语言中，增加了创建和撤销动态变量的两个操作符`new`和`delete`，提高类型安全性。例如，
下面创建一个int型的动态变量，p1指向之：
```cpp
int *p1; //p1是个指针变量
p1 = new int; //C++扩充，空间大小自动确定
```
下面创建一个由n个int型元素构成的动态数组，p2指向其第一个元素：
```cpp
int *p2; //p2是个指针变量
p2 = new int[n]; //C++扩充
```
下面撤销p1指向的int型动态变量：
```cpp
delete p1;
```
下面撤销p2指向的int型动态数组：
```cpp
delete []p2;
```

一般来说，
- 用`new`创建的动态变量需要用`delete`来撤销；
- 用`malloc`（`calloc`）创建的动态变量则需要用`free`撤销。
对于普通的动态变量，C++与C的做法区别不大，但如果创建的是动态对象，则两者是有差别的：
- 除了为对象分配空间外，`new`还会去调用对象类的构造函数进行对象初始化，`malloc`（`calloc`）则不会。
- 除了收回为对象分配的空间外，`delete`还会去调用对象类的析构函数进行对象消亡后的清理，`free`则不会。
C/C++动态变量的问题：
- 没有自动废区收集功能，动态变量需要程序显式用`free`或`delete`撤销，否则会出现内存泄漏问题！

### 引用类型
引用类型是用来给一个变量取一个*别名*，通过该别名可以访问原来的变量。
例如：
```cpp
int x;
int &y=x; //y为引用类型的变量，它是x的别名
y = 10;  //通过y访问x，效果上等价于：x = 10;
```
引用类型具有指针类型的一些效果，但语法不一样。例如：
```cpp
int *p=&x; //p为指针类型的变量，它指向x
*p = 20; //通过p访问x，效果上等价于：x = 20
```
引用主要用于函数的参数类型，实现指针类型参数的效果，但比指针类型抽象和安全。

#### 用引用类型提高函数参数传递的效率
例如：
```cpp
struct A
{ int i;
   ......
};
void f(A &x) //x使用实参a的内存空间，提高参数传递效率
{ ......
   … x.i … //访问实参
   ......
}
int main()
{ A a;
   ......
   f(a); //把a传给函数f
   ......
}
```

#### 用引用类型实现通过形参改变实参的值
例如：
```cpp
#include <iostream>
using namespace std;
void swap(int &x, int &y) //交换两个int型变量的值
{ int t;
 t = x;
 x = y;
 y = t;
}
int main()
{ int a=0,b=1;
 cout << a << ',' << b << endl; //结果为：0,1
 swap(a,b);
 cout << a << ',' << b << endl; //结果为：1,0
 return 0;
}
```

#### 引用类型的安全性
引用类型能保证通过形参访问的永远是实参数据，比指针更加安全。
```cpp
void f(int *p)
{ ... *p ... //访问的是实参a
   int m;
   p = &m; //OK
   ... *p ... //访问的是m，即通过p可以访问实参以外的数据
}
void g(int &x)
{ ... x ... //访问的是实参a
   int m;
   x = &m; //Error
   … x … //访问的是a ，即通过x只能访问实参数据
}
int main()
{ int a;
   f(&a);
   g(a);
}
```
当然，使用指针类型的常量也可以实现引用类型形参的这个效果：
```cpp
void f(int *const p)
{ ... *p ... //通过p访问实参
   int m;
   p = &m; //Error
   ... *p ... //通过p只能访问实参
}
```

##### 防止函数通过形参修改实参数据
使用const声明，具体见下文代码示例。
使用前：
```cpp
void f(int *p)
{ cout << *p; 
   *p = 20;
}
void g(int &x)
{ cout << x;
   x = 30;
}
......
int a=10;
f(&a); //调用中输出：10；
cout << a; //调用后a的值变成：20
g(a);  //调用中输出：20；
cout << a; //调用后a的值变成：30
```
使用后：
```cpp
void f(const int *p)
{ cout << *p; 
   *p = 20; //Error
}
void g(const int &x)
{ cout << x;
   x = 30; //Error
}
......
int a=10;
f(&a); //调用中输出：10；
cout << a; //调用后a的值不变，仍然为10
g(a);  //调用中输出：10；
cout << a; //调用后a的值不变，仍然为10
```

#### 函数引用类型
**函数返回值**可以为引用类型，其返回值具有特点：
```cpp
struct A
{ int n;
 ......
};
A func1(const A &x)
{ ...... 
   return x; //把x（也就是a）复制一份返回
}
A& func2(const A &x)
{ ...... 
   return x; //把x（也就是a）返回
}
......
A a;
a.n = 0;
func1(a).n++; //a.n的值没变（为0），因为修改的不是a
func2(a).n++; //a.n的值变了（为1），因为修改的是a
```

**注意：不要把局部量的引用返回给调用者，因为函数返回后，局部量的内存空间已无效，后续操作中可能又分配给其它变量！** 例如：
```cpp
int &f()
{ int i=0;
  return i; 
}
int &g()
{ int j=1;
  return j; 
}
int main()
{ int x ;
   x = f()+g();
  cout << x << endl; //输出：1？//可能是 2，因为j可能占用的是i的空间
  return 0;
}
```
#### 引用类型的实现
引用类型一般作为指针类型来实现（有时又把引用类型称作隐蔽的指针，hidden pointer）
对于下面的引用类型：
```cpp
void f(int &m) //m是引用类型
{ cout << m << ','   //输出m的值（实参的值）
          << &m; //输出m的地址（实参的地址）
}
......
int x=0,y=0;
f(x);   // f中的输出是x的值和地址
f(y);   // f中的输出是y的值和地址
int &z=x;   //z是引用类型
z = 1; 
cout << x << ',' << z; // 1,1
cout << &x << &z; //结果一样！
```

编译程序将按下面的指针类型来实现：
```cpp
void f(int *m) //m是指针类型
{ cout << *m << ',' //输出m指向的值（实参的值）
          << m;   //输出m的值（实参的地址）
}
......
int x=0,y=0;
f(&x); // f中的输出是x的值和地址
f(&y); // f中的输出是y的值和地址
int *z=&x; //z是指针类型
*z = 1; 
cout << x << ',' << *z; // 1,1
cout << &x << z;   //结果一样！
```
### 函数名重载
**同一个作用域内**，对于一些**功能相同**、*参数类型*或*个数*有所不同的函数，如果给它们取相同的名字有时会带来使用上的方便（便于理解和记忆）。

例如，把下面不同的函数：
```cpp
void print_int(int i) { ...... }
void print_double(double d) { ...... }
void print_char(char c) { ...... }
void print_A(A a) { ...... } //A为自定义类型
```
定义为同名的函数：
```cpp
void print(int i) { ...... }
void print(double d) { ...... }
void print(char c) { ...... }
void print(A a) { ...... }
```
在相同的作用域中，可以用同一个名字定义多个不同的函数，这时，要求定义的这些函数应具有不同的参数（参数个数或类型要有所不同）
##### 绑定
确定一个对重载函数的调用对应着哪一个重载函数定义的过程称为**绑定**（binding，又称定联、联编、捆绑）。
例如，print(1.0)调用的是下面的哪一个重载函数？
```cpp
void print(int i) { ...... }
void print(double d) { ...... }
void print(char c) { ...... }
void print(A a) { ...... }
```
对重载函数调用的绑定一般是==在编译时刻==由编译程序根据实参与形参的匹配情况来决定。

##### 重载函数的绑定规则
从形参个数与实参个数相同的重载函数中，按下面的次序选择一个：
- **精确匹配**
	- 实参与形参的类型**完全相同**，或者对实参进行“*微小*”的类型转换（如数组转换为指针类型）后与形参类型相同：
		- 数组变量名->数组第一个元素的内存地址
		- 函数名->函数的内存首地址
		- ......
	- 例如，对于下面的重载函数定义：
```cpp
void print(int);
void print(double);
void print(char);
void print(char *);
```
下面的函数调用
```cpp
print(1);  //绑定到函数： void print(int);
print(1.0); //绑定到函数：void print(double);
print('a');  //绑定到函数：void print(char);
char s[10]; //绑定到函数：void print(char *);
print(s);  
```
- **提升匹配**
	- 先对实参进行下面的类型提升，然后进行精确匹配：
		- 按整型提升规则提升实参类型
		- 把float类型实参提升到double
		- 把double类型实参提升到long double
-  **标准转换匹配**
	- 先进行下面的标准转换，然后进行精确匹配：
		- 任何算术类型可以互相转换
		- 枚举类型可以转换成任何算术类型
		- 零可以转换成任何算术类型或指针类型
		- 任何类型的指针可以转换成void *
- **自定义转换匹配**
- **匹配失败**
	- ==每个标准转换都是平等的，不存在哪个优先；如果存在多个标准转换后能精确匹配，则失败！（具有歧义）==
	- 如果不存在匹配或存在多个匹配，则绑定失败。例如，对于下述的重载函数：
		`void print(char);`
		`void print(double);`
		根据标准转换匹配，下面的函数调用将会绑定失败：
		`print(1);` 
		因为1（属于int型）既可以转成char，又可以转成double

### 基于范围的for
C++语言注重程序的效率，运行时刻不对数组元素下标越界进行检查，从而造成下面错误代码的执行不会报错：
```cpp
int a[10],sum;
for (int i=0; i<=10; i++) cin >> a[i];
sum=0; for (int i=0; i<=10; i++) sum += a[i]; 
```
为了方便、可靠地实现一些简单地对一维数组元素进行遍历的操作，在C++新国际标准（C++11以后）中提供了一种**基于范围的for语句**，它能自动遍历数组元素。
例如，给一维数组每个元素输入一个值：
```cpp
for (int &n: a) cin >> n; //可改变元素的值
```
再例如，对一维数组所有元素求和：
```cpp
sum = 0;
for (int n: a) sum += n; //不能改变元素的值
```
编译器会自动判断for函数的循环次数，无需人为确定。
### 自动判断类型
在C语言中，关键词auto用来显式指示具有自动生存期的局部变量。
在C++新国际标准（C++11以后）中，关键词**auto**有新的含义：
定义一个变量时可以==不指定==它的类型，==由编译器根据初始化的值自动确定它的类型==。例如：
```cpp
auto x=1+2*3.4; //编译程序自动确定x的类型为double
```
再例如：
```cpp
int f(double x) { ...... }
......
auto fp=f; //编译程序自动确定fp的类型为：int (*fp)(double)
```
因此，C++11以后，自动生存期的局部变量不能再显式地用auto来指出了！（C中的cuto不能再使用了）
### 字符串常量和字符指针
按C语言，可以；按C++语言，不可以！
```cpp
void f(char *p) { ...... }
void g(char x[]) { ...... }
......
char *p="abcd"; //Error
f("1234"); //Error
g("1234"); //Error
```
“1234”是一个常量，在运行过程中不可被改变，因此为了节省空间，在内存中只保存一份，而此时却将这个常量分给各种可以改变其值的变量，在C++中不被允许。
**解决方案：**
C++语言需要用指向常量的指针！
```cpp
void f(const char *p) { ...... }
void g(const char x[]) { ...... }
......
const char *p="abcd"; //OK
f("1234"); //OK
g("1234"); //OK
```
