C++ 与 C 的关系

C++ 包含了 C 的所有成分。
C++ 在 C 的基础上增加了一些新的语言机制：

  • 更好地支持过程式编程，提高与类型相关的安全性。（C++ 对 C 的基本扩充）
  • 支持面向对象编程。
  • 支持泛型编程。
  • 支持函数式编程。

基本扩充内容

  • 局部变量的定义位置：
    • 允许局部变量的定义可以加插在语句中
    • 变量的使用点和定义点相距不至于太远，便于理解与维护
  • 常量定义：
    • #define PI 3.1416 （编译前的预处理时会将 PI 替换为 3.1416）
    • C++ 补充了 const double PI = 3.1416，便于编译时进行类型检查
  • 表示条件的表达式：
    • 值非 0 表示满足，0 表示不满足
    • bool 类型：true 表示满足，false 表示不满足（C++ 扩充的，便于理解）
  • 内联（inline）函数：编译时把函数体嵌入到函数的调用点，提高对小函数的调用效率
  • 可以给函数的参数指定默认值
  • 名空间（namespace）：不同模块可以有同名的全局实体，应对名冲突问题
  • 标准库 ：保留了 c 的标准库，将头文件名从*.h 改为 c*，如stdio.h 改为cstdio
  • 函数名重载 ： 同一个作用域内 功能相同、参数不同的函数取相同名字
  • 动态变量的内存分配 ：增加了新的操作符new 与delete，保证类型安全。
  • 引用类型：具有指针的一些作用，但比指针更安全。
  • 基于范围的 for 语句：自动遍历数组元素，防止数组下标越界
  • 类型自动判断 auto：根据初始化的值自动判断变量的类型，方便某些类型变量的定义
  • 结构化异常处理：把程序的正常处理与异常处理的代码分离开，使得程序容易理解与维护。
  • 匿名函数（λ表达式）：把函数定义和使用合而为一，方便对一些临时函数的使用。
  • 输入 / 输出：保证类型安全的输入输出（cin、cout 等）

  • 带参数的宏 如#define max(a,b) (((a)>(b)?(a):(b))

一般来说，

  • 用 new 创建的动态变量需要用 delete 来撤销；

  • 用 malloc（calloc）创建的动态变量则需要用free 撤销。对于普通的动态变量，C++ 与 C 的做法区别不大，但如果创建的是动态对象，则两者是有差别的：

  • 除了为对象分配空间外，new还会去调用对象类的构造函数进行对象初始化，malloc（calloc）则不会。

  • 除了收回为对象分配的空间外，delete还会去调用对象类的析构函数进行对象消亡后的清理，free则不会。
    C/C++ 动态变量的问题：

  • 没有自动废区收集功能，动态变量需要程序显式用 free 或delete撤销，否则会出现内存泄漏问题！
